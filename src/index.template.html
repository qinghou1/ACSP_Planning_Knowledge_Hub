Developer handoff & shared maintenance

One source of truth

The ZIP contains editable source files, JSON data, validation and build scripts, contribution templates, and GitHub workflows. Build the portable HTML from those files rather than editing generated copies.

src/                 HTML template, CSS, JavaScript
data/collections/    One file per collection
data/resources/      One file per resource
scripts/             Validate, import, and build
docs/                Setup and maintenance guides
.github/             Issues, checks, deployment

Local build, with Python 3.10 or newer:

python scripts/validate.py
python scripts/build.py
python -m http.server 8000

Contribute from any university

Use a shared organization-owned repository. Contributors can fork it, make changes on a branch, and propose a pull request. Assigned maintainers can then merge changes and publish a new version.

Committee editors maintain content; student developers maintain code and documentation. Keep at least two maintainers and document handovers so access does not end with one student's appointment.

Connect the public workflow

Set githubRepository in data/config.json to the real owner/repository, enable Issues, and configure GitHub Pages. Rebuild the HTML. The repository and submission links will then use that location.

Repository permissions and branch rules must be configured by an administrator. The included CODEOWNERS example does not grant access. Select and approve a code license before describing the project as open source.

The local form is not a content management system. Authenticated, non-GitHub publishing would require a separately configured service.

About this direction

A shared hub, not a single-topic site.

Inclusive scope

Planning and allied fields

The hub brings together education, research, and practice across planning, policy, geography, design, environment, public health, and technology. AI is welcome but never required.

Distributed contribution

Groups keep their identity

Collections make committee and institutional contributions visible within a common library. Shared metadata supports discovery without forcing every group into an AI-centered structure.

Shared stewardship

Continuity beyond one team

Documented source files and contribution pathways support collaboration across universities. Platform ownership, publishing access, and maintenance responsibilities still need to be assigned.

Prototype status, local storage & attribution

No official organizational name, committee assignment, or affiliation is asserted by this prototype. The published catalog starts empty, as in the original HTML. Example entries are fictional and are excluded from published counts. Drafts remain on this device unless you explicitly export or share them. Local storage is not encrypted and should not contain confidential information. External resource links and GitHub submissions take you to third-party websites. Source material retains its original reuse conditions.
