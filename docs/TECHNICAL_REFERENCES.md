# Technical references

Official GitHub documentation consulted for this package on September 30, 2026. These references support the proposed platform configuration, not a claim that a repository has already been deployed.

1. **GitHub Pages is static hosting.** Explains HTML/CSS/JavaScript hosting and repository-based site deployment.  
   https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
2. **Contributing to a project.** Describes forks, branches, and pull requests for contributors without direct write access.  
   https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-a-project
3. **Creating an issue.** Includes title/body URL parameters, template selection, permissions, and URL-length failure conditions. The site uses a conservative application-level 7,000-character prefill cutoff, not a claimed GitHub limit.  
   https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-an-issue
4. **Using custom workflows with GitHub Pages.** Covers configure-pages, upload-pages-artifact, deployment permissions, environments, and job dependencies.  
   https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
5. **About code owners.** Covers assignment, repository permissions, review requests, and branch-protection integration.  
   https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners
6. **About protected branches.** Explains checks, required reviews, force-push restrictions, and administrator configuration.  
   https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches
7. **Licensing a repository.** Explains why open-source licensing requires an actual license decision rather than public visibility alone.  
   https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository

These documents may change. Check the current repository/account interface during deployment. No live GitHub write, remote issue submission, permission assignment, or Pages deployment was performed while preparing this package.
